# Sprint 13 变更说明（2026-09-20）

本轮主题：**把「看起来能点、但点了没用 / 数值是假的」的地方全部改成真的做事的。**

起因是这批 12 张截图（6 界面 × 亮暗）逐张核对时发现：「我的 → 设置框」六行都带 `›` 箭头，

既不是当前设置、也改不了。这与项目红线（不装样子）直接冲突。

## 二、修的三处问题

### 1. 浅色模式卡片与白底糊在一起 → 统一卡片容器 `appCard`
`DesignTokens` 新增 `View.appCard(_ scheme:cornerRadius:)`：底色 + 圆角 + **一圈 0.5px 细描边**。
描边用既有的 `appBorder`（浅 `#DDD8E8` / 深 `#333333`），依旧是「扁平、无阴影」的设计语言。
已套用：「我的」的 4 个卡片、账号与安全的 2 个卡片（原来同样看不见）。

### 2. 收藏时间改中文
新增 `RelativeDateText`：`今天 09:02` / `昨天 21:04` / `9月18日` / `2025年9月18日`。
只用于**客户端自己产生的时间**（收藏时间、上次刷新时间）；
论坛页面给出的时间原文（如「2004-11-3 22:22」）一律原样展示，不做二次翻译，避免两边口径不一致。

### 3. 截图不再依赖外网图源
图片全屏在 Demo / 截图模式下改用**本地绘制**的渐变占位图（`DemoGalleryImage`），
真实模式仍走 `AsyncImage` 网络加载。CI 断网也能稳定出图，不会再出现「一直转圈」的截图。

## 三、设置框：六行全部可点、且真的生效

| 设置项 | 之前 | 现在 |
|---|---|---|
| 主题外观 | 死箭头，值「跟随系统」是唯一真实项 | → 进「阅读设置」（主题 / 字号 / 行距 / 列表密度） |
| 回帖占位符 | 死箭头，值写死 `Peace&Love` | → 进新页面**可编辑**，带效果预览；回复框与发帖框立即用新值 |
| 显示帖子正文 | 死箭头，值写死「开」 | → **就地开关**；关掉后首页 / 搜索列表只显示标题，真实省屏幕 |
| 版块管理 | 死箭头 | → 进真实的板块排序页（持久化，决定首页板块顺序） |
| 消息推送 | 死箭头，值写死「15 分钟」 | → 进新页面选关闭 / 15 / 30 / 60 分钟，并驱动**真实后台刷新** |
| 账号与安全 | 已可用 | 不变 |

新增的本地偏好统一放在 `PreferenceStore`（`UserDefaults` 支撑的 `ObservableObject` 单例），
**不再往 SwiftData 里加字段**：这些开关要在 App 启动早期和后台任务里读取，
放 `UserDefaults` 既快、又完全避免既有安装的数据迁移风险。

## 四、真实后台刷新（消息推送）

新增 `Core/BackgroundRefresh.swift`：

- `BGAppRefreshTask` 注册 + 按用户设定的间隔排期；
- 触发时拉一次 `pm.php` 收件箱，把**真实未读数**写入消息 Tab 角标（与前台同一口径）；
- 未登录 / 网络失败只是「没刷新」，不改动任何角标数字，更不会伪造未读；
- 回到前台时，若开启了推送间隔，顺手核对一次未读。

**稳定性设计**：`BGTaskScheduler.register` 要求标识已写进 Info.plist 的
`BGTaskSchedulerPermittedIdentifiers`，否则会抛 ObjC 异常**直接崩溃**。
因此代码先检查构建配置再注册，缺配置时安静降级为「不刷新」并记录日志，绝不崩。
配套新增 `Support/Info.plist`（`UIBackgroundModes: fetch` + 任务标识），
`project.yml` 改为 `INFOPLIST_FILE: Support/Info.plist` + `GENERATE_INFOPLIST_FILE: NO` ——
因为数组类型的键无法用 `INFOPLIST_KEY_*` 构建设置表达。
plist 放在 `Support/` 而不是 `App/`：`Support` 不在 `sources` 里，绝不会被当成资源重复拷贝。

设置页如实写明：**实际唤醒时机由 iOS 决定，不保证准时，也不保证每次都能唤醒**。

## 五、顺手消灭的假按钮

首页信息流的「分享 / 收藏」两个图标原来点了没有任何反应，现在：

- **分享** → 系统分享面板（分享该帖网页地址）；
- **收藏** → 真实本地书签（与详情页同一份 `SavedThread` 数据，实心金色 = 已收藏）。

搜索结果页同样复用 `PostRow`，作者名与星标一并接上真实动作（作者名 → 用户卡；星标 → 本地收藏）。

## 六、论坛侧能力查证（新增一条结论）

`评分`（Discuz 的帖内评分 `misc.php?action=viewratings`）在 4D4Y 模板里**同样不存在**：
真实 `viewthread.php` 页面全文搜不到「评分 / rate」入口，`viewratings` 只出现在
`disallowfloat` 配置串里。因此原计划里的「站内评分」一项**在本站点无法实现**，
与「收藏 / 分享」同属模板已关闭的功能，不再列入待办。
