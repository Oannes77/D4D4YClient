## 三、尚未在真机验证的部分（本地无登录态）

> 论坛侧 `search` / `pm` / `my` / `space` **游客全部不可达**，本地只能防御式实现。
> 客户端统一约定：**需要登录 → `.requiresLogin`（给登录入口）；抽不到结构 → `.unsupported`（明说可能已变化）**，
> 绝不用空列表冒充「你没有内容」。

- `my.php`（我的中心）列表结构
- `pm.php`（私信）会话结构
- `space.php`（用户资料）字段结构
- `search.php` 结果结构

这些登录后在真机上可能因模板差异走到「结构未识别」态 —— 届时按真实 HTML 再校准。

## 四、下一轮建议（低风险优先）

1. **打通用户卡三个死按钮**（加好友 / 搜贴 / 拉黑）——这是目前唯一有「点了没反应」的地方，违反项目红线，优先级最高。
2. **帖子详情内嵌图片的浏览体验打磨**——游客可见、本地可验证、风险最低。
