# Sprint 14 变更说明

> 主题：把「我的」宫格里最后四个入口接上真实内容，并补齐首页板块的左右滑切换。

## 一、这轮做了什么

### 1. 「我的」宫格四个入口从「说明页」升级为真实列表

上一轮宫格里的 帖子 / 回复 / 好友 / 关注 点进去只是「尚未接入 + 网页版出口」的说明页。
这轮接上论坛「我的中心」（`my.php`）：

| 入口 | 现在真做什么 |
|------|-------------|
| 帖子 | `my.php` 的「我的话题」列表，点某条进帖子详情 |
| 回复 | `my.php` 的「我的回复」列表，点某条进帖子详情 |
| 好友 | `my.php` 的「好友」用户列表，点某个弹用户卡 |
| 关注 | Discuz! 7.2 没有这个栏目 → **如实说明** + 网页版出口（不给空列表） |

新增文件：

- `Models/MySpaceModels.swift` —— 栏目定义 `MySpaceKind`、条目 `MySpaceEntry`、加载态 `MySpaceLoadState`
- `Parsers/MySpaceParser.swift` —— 导航动态发现 + 通用锚点抽取
- `Repositories/MySpaceRepository.swift` —— `my.php` 读取（含失败态）
- `Features/Profile/MySpaceListView.swift` —— 列表页与各种状态

**不硬编码 `item=` 参数**：先 GET `my.php`，从页内导航把「item 参数 → 栏目名」解析出来，
再按栏目名匹配。站点换模板 / 改名时客户端自动跟随；站点确实没有这个栏目时，
能**准确区分**「没有」与「读不出来」，不会用空列表冒充「你有 0 个关注」。

抽取规则（不依赖具体 class 名）：

- 帖子型：取 `a[href*=viewthread.php]`，同一 tid 取**文本最长**的那条当标题；
  「明细」= 所在容器文本剔除标题与时间后的剩余部分（版块名等）；
- 用户型：取 `a[href*=space.php?uid=]`，按 uid 去重，显示名同样取最长文本。

### 2. 首页板块支持左右滑切换

产品框架里锁定过「板块可左右滑切换」，此前只有点击胶囊。现在在首页内容区加了横向滑动手势：

- 只在**横向意图明显**时触发（位移 > 70pt，且大于纵向位移的 1.5 倍），不影响上下滚动；
- 滑到第一个 / 最后一个板块即停住，不循环；
- 选中逻辑统一走 `select(_:)`：记录访问 + 刷新该板块；演示模式下不联网。

### 3. 首页信息流补上「列表密度」

阅读设置里的「列表密度」原本只在楼层（`PostCell`）与论坛主题列表（`ThreadListView`）生效，
首页信息流 `PostRow` 没接 —— 同一设置在不同列表表现不一致。现在统一：紧凑 8 / 标准 12 / 宽松 18。

## 二、截图验收

默认只跑本轮新增 / 待验收的 5 个界面（亮 + 暗 = **10 张**）：

| DemoScreen | 看什么 |
|-----------|--------|
| `myThreads` | 我的帖子列表（标题 + 版块 + 回复数 + 时间） |
| `myFriends` | 好友列表（头像 + 名字 + 分组 + UID） |
| `myFollows` | 「本站没有这个栏目」的说明页 + 网页版按钮 |
| `replyPlaceholder` | 上轮新增、尚未验收的回帖占位符设置页 |
| `pushSettings` | 上轮新增、尚未验收的消息推送设置页 |

上一轮验收过的 home / search / imageViewer / profile / savedThreads 已移入 `confirmedTargets`。
全量回归仍是 `SCREENSHOT_FULL=1`（22 个界面 = 44 张）。

顺带把截图脚本的等待逻辑改成**同时盯按钮与静态文本**（原先先试按钮 12s 再试文本 3s），
导航栏标题类锚点几乎立即命中，单屏等待时间明显下降。

## 三、没能本地验证的部分（如实说明）

`my.php` 必须登录才可达（游客返回「对不起，您还未登录，无法进行此操作。」+ 登录表单），
且 4D4Y 的定制 wap 模板里没有任何 `my.php` 链接，所以列表结构**本地无法验证**。
本轮采用防御式实现：有内容 / 真空 / 需要登录 / 本站无此栏目，四种结果分别如实呈现。
真机登录后若发现结构不同，界面会走「结构未识别」并给出重试与网页版出口，不会显示假内容。
